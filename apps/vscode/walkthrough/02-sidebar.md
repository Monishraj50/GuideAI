# The sidebar — three views, four buttons

Click the **Atrune** icon in your activity bar (left edge of VS Code) to open the sidebar.

## What you'll see

**Three tree views** — the only ambient state:

| View | Answers |
|---|---|
| 🎯 **Active work** | "What's running right now? What phase is it in?" |
| ✅ **Pending** | "What needs a decision from me?" (badge count on the icon) |
| 👥 **Team** | "Who's on the team? Right-click an agent to send a direct task." |

**Four toolbar buttons** on the Active work title:

- 💬 **New brief** — write a brief and dispatch the pipeline
- ⚡ **Quick ask** — abbreviated single-agent or auto-fix
- 📦 **Mission Control** — the entire web UI in a tabbed webview
- ⚙️ **Settings** — VS Code settings filtered to Atrune

The principle: only interrupt-driven *state* lives in the sidebar. Every *action* is a button or command.

# Quick ask — fix one thing fast

Some moments don't need the full ceremony. Two lightweight paths skip discovery + critic:

## Auto-fix this file

- **Right-click any file** in the Explorer → **Atrune: Auto-fix this…**
- Type a 1-sentence description (e.g. *"add input validation to the /shorten endpoint"*)
- Atrune picks (or hires) the right agent and runs a 3-phase abbreviated pipeline

## Ask one agent

- Click ⚡ **Quick ask** in the Atrune sidebar → **Ask one agent**
- Pick an agent from your roster
- Type the prompt; their response opens as a Markdown editor tab

## Selection-based

- **Select code in the editor** → right-click → **Atrune: Ask agent about this selection**
- The selected text is included as context

All three respect the same budget guardrails as full briefs. The cost preview popup will tell you what to expect before you confirm.

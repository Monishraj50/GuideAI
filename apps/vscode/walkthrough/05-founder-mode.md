# Founder mode — speak plain English

If words like *"build"*, *"verify"*, or *"Bash"* aren't your daily vocabulary, flip on Founder mode.

## Turn it on

- ⚙️ **Open Settings**
- Search **`atrune.founderMode`**
- Toggle it on

## What changes

| Developer mode | Founder mode |
|---|---|
| `building · Add validation to /shorten` | `your team is writing the code · Add validation to /shorten` |
| *Atrune wants to use Bash* | *Atrune wants to run a command* |
| *Active work* (tree view) | *What we're doing* |

Same data, friendlier words. You can flip it on or off any time — same person, different mood.

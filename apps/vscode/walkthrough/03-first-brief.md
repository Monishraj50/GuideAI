# Your first brief

Click 💬 **New brief** in the Atrune sidebar (or press **⌘⇧B** on Mac / **Ctrl+Shift+B** on Windows/Linux).

You'll see a picker first:

- **Blank brief** — write your own from scratch
- **Six starter templates** — Build a website, Build an API, Write documentation, Audit security, Design a UI, Refactor code

Pick one, edit the body, hit **Dispatch**.

## What happens next

A 5-phase pipeline runs:

1. **Research** — agents gather context from your repo + the web
2. **Plan** — they draft a plan; a critic agent reviews it
3. **Implement** — code/docs/configs get written
4. **Review** — a different model checks the work
5. **Verify** — tests, lint, and where applicable a browser smoke test

You'll see the narrator change in the status bar as each phase ticks through:

> `$(sync~spin) Atrune · building · Add validation to /shorten · $0.12`

Click the status bar at any time to open the full Mission Control for details.

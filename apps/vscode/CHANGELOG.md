# Changelog

## 0.1.0 — Initial release

### Added

- Three sidebar TreeViews: Active work · Pending · Team
- Toolbar buttons: New brief, Quick ask, Mission Control, Settings
- Auto-spawn for the Atrune server + Next.js web on activation
- Mission Control webview (iframe over the existing Next.js UI with port mapping)
- Native brief composer with the workspace dropdown + securityTagged checkbox
- Direct task mode: `askOneAgent` and `autoFix` flows
- Editor + Explorer context menus: Auto-fix this · Ask agent about this selection
- Status bar item: health dot + live narrator + budget HUD + pending count
- Native approval popups via `vscode.window.showInformationMessage`
- Six project templates (website / API / docs / audit / UI / refactor)
- Cost preview modal before paid actions
- Founder mode setting — plain-English labels for narrator + approval popups
- Native walkthrough (5 steps) on first activation
- 5-second polling cadence for sidebar refresh + status bar update
- Custom cube mark optimized for the activity bar (currentColor + teal accent)

### Branding

- Renamed from Atrium.AI to AtruneAI (the "AI workplace where your team _attunes_ to the work")
